# actus-rs

A deterministic state-transition engine for financial contracts, implementing the
[ACTUS](https://www.actusfrf.org) standard in Rust.

- **All 18 contract types of the ACTUS technical specification**: PAM, LAM, LAX, NAM, ANN, CLM,
  UMP, CSH, STK, COM, FXOUT, SWPPV, SWAPS, CAPFL, OPTNS, FUTUR, CEG, CEC.
- **Passes all 276 official ACTUS test cases**, compared to ~1e-9 (the reference Java test harness
  only compared integer parts).
- **Fixed-point arithmetic**: `Fixed<S>` with `S` decimals (default 18), `i128` storage, 256-bit
  intermediates, half-even rounding. No floating point anywhere in the engine; overflow and
  division by zero become errors, never wrong numbers.
- **Pure core**: `step(terms, state, event, observer) -> (state, payoff)`. All external inputs
  (rates, prices, FX, unscheduled events) come through one observer interface, so every run can be
  recorded and replayed exactly (`observer::Recorder`), and `required_inputs` tells you which
  observations an event needs before you run it.
- **Lazy evaluation**: `stream()` yields events one by one and handles contracts with no end date.

## Usage

```rust
use actus_rs::{Contract, Fixed, MarketData};

let loan: Contract = Contract::from_json(&serde_json::json!({
    "contractType": "PAM", "contractID": "loan-1", "contractRole": "RPA",
    "statusDate": "2024-01-01T00:00:00", "initialExchangeDate": "2024-01-02T00:00:00",
    "maturityDate": "2025-01-02T00:00:00", "currency": "USD",
    "notionalPrincipal": "1000000", "nominalInterestRate": "0.05",
    "dayCountConvention": "A360", "cycleOfInterestPayment": "P1ML1"
}))?;
for result in loan.stream(&MarketData::new()) {
    let r = result?;
    println!("{} {} {}", r.event.time, r.event.event_type, r.payoff);
}
```

See `examples/quickstart.rs` for a floating-rate loan with market data.

## Examples: one per contract type

Each example describes the contract, sets up a realistic scenario with every term commented,
supplies the market data and observed events it needs, and prints the resulting events with an
explanation. Run one with `cargo run --example <name>`.

| Type | Example | Scenario |
|---|---|---|
| PAM | `pam_bullet_loan` | 3-year floating-rate bullet loan, SOFR + 2% |
| LAM | `lam_linear_amortizer` | Equipment loan, fixed principal per quarter |
| NAM | `nam_negative_amortizer` | Fixed monthly payment, rising rates, balloon at maturity |
| ANN | `ann_annuity_mortgage` | Mortgage whose instalment is recalculated after each reset |
| LAX | `lax_construction_loan` | Two draw-downs, then amortization, with a rate step-up |
| CLM | `clm_call_money` | Call money called with 31 days' notice |
| UMP | `ump_savings_account` | Savings account with deposits and withdrawals |
| CSH | `csh_cash_position` | Cash position as the base of a liquidity ladder |
| STK | `stk_equity_position` | Shares with quarterly dividends, then sold |
| COM | `com_commodity_position` | Gold held for a year, marked to market |
| FXOUT | `fxout_fx_forward` | EUR forward, delivered vs. cash-settled |
| SWPPV | `swppv_plain_vanilla_swap` | Pay-fixed interest rate swap |
| SWAPS | `swaps_cross_currency_swap` | USD/EUR cross-currency swap built from two PAM legs |
| CAPFL | `capfl_interest_rate_cap` | Rate cap on a EURIBOR loan |
| OPTNS | `optns_equity_option` | European call and put on a share |
| FUTUR | `futur_commodity_future` | Jet fuel future, long and short side |
| CEG | `ceg_loan_guarantee` | 80% guarantee on an SME loan that defaults |
| CEC | `cec_collateral` | Gold-secured loan, default before and after a price crash |

## Conformance tests

The official test files are CC BY-SA and not included. Check out
[actus-tests](https://github.com/actusfrf/actus-tests) at `../ref/actus-tests` or set
`ACTUS_TESTS_DIR`, then:

```sh
cargo test                              # unit, conformance and invariant tests
cargo run --example conformance         # pass/fail summary per contract type
cargo run --example conformance pam pam25   # one case, computed vs expected
```

## Where this differs from the ACTUS spec

The official tests were generated by the 2020 Java reference implementation, which disagrees with
the written spec in many places, and the spec has errors of its own. Every such point, and what
this engine does, is documented in `docs/notes/`. Design decisions are in `docs/DESIGN-LOG.md`.
